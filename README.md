# 3D 国际象棋

GodotParty API 4 小游戏源码包。全幅棋盘、透视视角、原创三维棋子，以及沿用空白模板的贴边标题、状态和操作提示；使用原版协议的加载、手动准备与自动结算页面。引擎验证版本为 Godot 4.7.2。

## 安装与开局

将本仓库放到 GodotParty 的 `games/minigame/godot_party_default_3d_chess/`，由兼容的主游戏把包 ID `godot_party_default_3d_chess` 加入可选池。依赖当前 `godot_party_default_protocol` 1.0.0，须提供 `round_pages`、`briefing_gate`、`settlement_gate` 与 `font_sans` 公开资源。

本仓库是小游戏包，不是另一套独立大厅或框架，不包含 `project.godot`。不自动修改主仓 `.gitmodules`、正式轮换白名单或其他游戏。仅复制包还不会越过主游戏的白名单；需要由主游戏作者显式纳入。

房间支持 2–8 人，每张棋盘只有两个对弈席位。主游戏可显式传入两名参赛者，其余房间成员按框架观战；如果主游戏传入超过两人，则使用本轮种子确定两席，其余人在本局观战、结果不排名。不包含电脑棋手或同屏双人。

每位参赛者在协议加载页按 Enter 或空格准备，全部必要端准备完毕后倒计时三秒开局。结算页全部客户端加载完成后倒计时三秒自动结束，再由父主游戏继续。

## 操作

- 鼠标左键选择己方棋子，再选择标出的合法落点。
- 鼠标右键拖动旋转视角，滚轮缩放；默认 R 恢复本方视角，Tab 打开棋局面板。
- 兵到达最后一排时选择后、车、象或马。
- 左下“棋局”展开玩家、棋谱、规则与和棋 / 认输操作；不常驻占用棋盘。
- 可主张和棋时显示“申请和棋”。如果要依据下一步申请，先点击该操作，再选择造成三次重复或五十回合的合法着法；主张成立时不执行该步。
- Esc 使用 GodotParty 菜单。设置界面阻断棋盘操作，不暂停对方或网络。

## 本机配置

在大厅“小游戏池”中选中本游戏，打开右侧“本机设置”，可调整合法落点提示、旋转灵敏度，以及恢复视角和棋局面板的主键 / 备用键。应用后立即生效，HUD 和加载页显示当前绑定；空绑定可通过屏幕操作使用功能。左键选棋、右键旋转、滚轮缩放与 Esc 导航作为固定操作展示。设置仅保存到本客户端，不进入房主规则或棋局网络状态。

画质、渲染比例和抗锯齿继承原版协议，也可以通过框架的本游戏协议覆盖独立设置。游戏登记根视口、灯光与材质目标，不复制协议画质字段。进入系统菜单或本地设置时隐藏棋局 HUD 并阻断棋盘输入，返回后恢复；网络对局仍会继续。

## 棋规与结果

合法着法经过国王安全检查，包含将军、将死、逼和、两侧王车易位、吃过路兵与全部四种升变。王不能被吃，不能穿越受攻击格进行易位，吃过路兵不能暴露己王。局面重复计入行棋方、易位权和实际可用的吃过路兵权。

三次重复和五十回合规则需行棋方主张；五次重复与七十五回合自动和棋，将死优先于七十五回合判定。自动识别常见不可能将死的子力组合，包括单王、王加单象/马、仅同色格象。任意封闭兵链等非常规死局没有通用求解器，可由双方协议和棋。依据 [FIDE 国际象棋规则](https://handbook.fide.com/chapter/e012023)。

普通局 `standard` 返回本轮局部分数：胜 1、负 0、和棋各 0.5；名次由本局结果确定。观战者不排名，退出的对弈者标记 withdrawn，另一位仍在线棋手获胜。房主退出遵循框架的会话终止规则。不处理父主游戏奖励、金币或资源下注，不接受 `resource` 请求。

没有棋钟、超时判负、悔棋、断线重连、主机迁移、排位匹配或 AI。棋谱显示 SAN，最终 FEN 与棋谱保存在协议结果的 `game_data` 中；不另存个人文件。

## 实现边界

- `chess_rules.gd`：纯棋规、FEN、SAN、重复局面与和棋判定。
- `game.gd`：作用域生命周期、固定席位、房主权威动作验证和一次性结果提交。
- `chess_view.tscn` / `chess_view.gd` / `piece_mesh.gd`：三维表现与交互，不决定合法性或网络权限。
- `settings.gd`：Schema 3 本机操作和棋盘偏好。
- `adapter.gd` / `manifest.json` / `i18n/`：原版协议适配与包声明。

消息通过 PartyNet 的可靠、作用域隔离通道发送。动作包含会话、作用域和状态版本；房主从真实发送者解析身份，拒绝观战者、错方、非法着法与旧版本。客户端只接收房主状态。退出时停止视图与协议辅助资源。共享画质通过 `godot_party_graphics_targets()` 登记，不改框架或其他视口。

棋盘、棋子与封面均为本仓库原创几何/矢量内容；字体运行时引用协议公开资源，不复制外部资产。临时验证脚本、日志、截图和用户配置不随源码包提交。

## 验证

针对 GodotParty `b0fa1b9` / Godot 4.7.2：六组标准 perft 与 48 项棋规断言通过；初始局面深度 4 为 197281，Kiwipete 深度 3 为 97862。双端本机 ENet 验证了将死、协议和棋、认输、重复/非法消息拒绝与多局重入；三端验证了观战房主、断线、两席加观战及真实走棋后的三次重复主张。均核对一次性结果落盘与作用域清理。新增本机配置通过真实 PartyConfig 保存与原生鼠标 / 键盘回归，核对了两端偏好隔离、重绑与提示同步、合法点显示、灵敏度、设置页输入阻断及重入后持久化。1920×1080 实际窗口完成了选子、走棋、棋局面板与 Esc 操作验收。这些是本机真实多进程测试，不代表外网、Steam 或弱网验收。
